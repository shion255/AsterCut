# <img src="icon.png" width="40" alt=""> AsterCut

<img width="1104" height="892" alt="astercut" src="https://github.com/user-attachments/assets/a1c2fadb-b958-4649-94a4-5c358a67b260" />

FFmpeg の **trim ビットストリームフィルター**を使って、動画を無劣化で切り出す、Windows 向けの動画編集ツールです。
mpv のプレビューで映像を確認しながら区間を指定し、単一区間の切り出しと分割はストリームコピーのまま、複数区間の結合は再エンコードで行います。
仕様の詳細は [Spec.txt](Spec.txt) にまとめています (アプリ内の「仕様・使い方」でも読めます)。


## 無劣化カットについて

本ツールの無劣化カットは、FFmpeg に新しく追加された [trim ビットストリームフィルター](https://code.ffmpeg.org/FFmpeg/FFmpeg/commit/3a165c77dce7fac8c54f9f9aaab5447590433748) を核にしています。

- trim が指定区間のパケットを選び取り、タイムスタンプの間隔を保ったまま先頭へ揃え直すことで、ストリームコピーのまま切り出しを実現します
- 無劣化である以上、切り出す範囲はフレーム単位の指定どおりにはなりません。開始は復号のため手前のキーフレームから取り込み (指定位置までのフレームもファイルに残ります)、終了は範囲の外を参照する B フレームを含められないため、終了位置以前の最後の I / P フレームまでになります。参照先のないフレームが出力に入ることはありません
- 取り込んだ先頭の余分 (プリロール) の見え方は、出力コンテナで変わります
  - MP4 / MOV では、edit list で表示の開始を指定位置のフレームに揃えるため、edit list を読むプレーヤーでは見た目の開始が指定位置のフレームちょうどになります。ソースが MP4 系の場合に、この無劣化カットが最も活かされます
  - MKV / TS など edit list のないコンテナでは、表示はキーフレームから始まります。末尾を I / P フレームで止める処理と、音声の長さを映像に揃える処理は、コンテナによらず効きます
- ストリームコピーの出力は、入力と同じコンテナで出します。番組情報やデータ放送など、移し先のコンテナに正規の格納方法のないストリームを落とさないためです
- フレーム単位で厳密に切りたい場合は再エンコードで対応します。再エンコードでは、開始位置のフレームから終了位置のフレームまでフレーム単位で一致し、コンテナによる違いはありません。ただし、フレーム表が作れない素材や、素材に復号できないフレームが含まれる場合など、一部に例外があります (詳細は [Spec.txt の該当箇所](Spec.txt#L265-L270) またはアプリ内の「仕様・使い方」を参照)
- 複数区間の結合は、継ぎ目を整えるため再エンコードします。再エンコードするのは、結合やクリッピングした区間など、必要な部分だけです

無劣化カットには、trim / setts ビットストリームフィルターを含む FFmpeg ビルド (FFmpeg-Builds の最新ビルドなど) が必要です。対応しているかどうかは起動時に自動で確認し、「ツール」メニューの「オプション」画面に表示します。

## できること

- 区間のカット (trim / setts ビットストリームフィルターによる無劣化処理 / 再エンコード)、複数区間の結合、区間ごとの分割出力、全区間分割
- 区間ごとのクリッピング (上下左右の切り取り)
- 回転 (メタデータのみの変更)、再生速度の変更
- 音声トラックの選択 (保持するトラックの指定)
- サムネイル・字幕・チャプター・番組情報・データ放送の保持の選択 (単一区間と全体の出力が対象)
- 出力プロファイルによる再エンコード設定の切り替え (映像: AVC / HEVC / AV1、音声: AAC / Opus / FLAC、コンテナ: MKV / MP4 / WebM / TS)
- ストリームコピーの出力は、入力と同じコンテナで出力 (プロファイルのコンテナを使うのは再エンコード時)
- TS から TS への出力 (単一区間の無劣化カットと、条件を満たす再エンコード) では、番組情報・字幕・データ放送を引き継ぐ
- 編集履歴の復元と、編集プロジェクト (.acproj) の保存・読み込み (入力欄へのドラッグ＆ドロップでも開けます)
- チャプターの作成と読み込み、MPC-HC チャプター (.xchp) と MKV チャプター (.xml) の出力
- ffmpeg / ffprobe / ffplay の自動更新 ([FFmpeg-Builds](https://github.com/FFmpeg-Builds/FFmpeg-Builds) の最新ビルドへ)
- 出力ファイルへの編集情報のメタデータ記録

## ダウンロード

[リリースページ](https://github.com/shion255/AsterCut/releases) から zip をダウンロードできます。zip を展開して AsterCut.exe を実行してください (同じフォルダーの DLL ファイルも一緒に必要です)。

## 動作環境

- Windows
- 自己完結型の実行ファイルのため、.NET ランタイムの別途インストールは不要です

## 必要な外部プログラム

- ffmpeg.exe / ffprobe.exe (DLL を含む、同じ配布物の bin フォルダーごと使用してください)
- [mpv.exe](https://mpv.io/) (動画プレビュー用)

「ツール」メニューの「オプション」画面でパスを指定するか、exe と同じフォルダーに置いてください。

## ビルド方法

.NET 8 SDK でビルドします。

```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true
```

生成された AsterCut.exe と、同じフォルダーの DLL ファイルを一緒に配置してください。

## 設定ファイル

設定は、exe と同じフォルダーの AsterCut.settings.json に保存されます。
再エンコード設定のプロファイルは、exe と同じフォルダーの profiles フォルダーに、プロファイルごとの JSON ファイルで保存されます。
